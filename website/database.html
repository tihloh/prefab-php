Database

Create a reusable database connection before adding database-backed modules.

Install

composer require tihloh/prefab-database

Create a tutorial database

Create a database named prefab_tutorial in MariaDB/MySQL using phpMyAdmin, Adminer, MySQL CLI, or another database tool.

Connect with PDO

$pdo = new PDO(
    'mysql:host=127.0.0.1;dbname=prefab_tutorial;charset=utf8mb4',
    'root',
    '',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

$pdo->query('SELECT 1');
Windows and Linux use the same PHP/PDO code. Database service installation and credentials may differ.
Checkpoint: the test query runs without an exception.
