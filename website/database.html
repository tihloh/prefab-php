Database

Connect to MariaDB/MySQL, then learn CRUD, raw SQL, transactions and diagnostics in small testable steps.

1. Install

composer require tihloh/prefab-core

2. Create a small test table

CREATE DATABASE prefab_tutorial;
USE prefab_tutorial;

CREATE TABLE users (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(190) NOT NULL UNIQUE,
    active TINYINT(1) NOT NULL DEFAULT 1
);

3. Connect

Create database-test.php:

<?php
require __DIR__ . '/vendor/autoload.php';

use Tihloh\Prefab\Core\Database\DatabaseManager;

$pdo = new PDO(
    'mysql:host=127.0.0.1;dbname=prefab_tutorial;charset=utf8mb4',
    'root',
    '',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

$database = new DatabaseManager($pdo);

var_dump($database->ping());

Run it:

php database-test.php

Continue only when it returns true.

4. Insert one row

Add this below the connection code:

$id = $database->table('users')->insertGetId([
    'name' => 'Demo User',
    'email' => 'demo@example.com',
    'active' => true,
]);

echo "Created user #{$id}";

5. Read it back

$user = $database->table('users')
    ->where('id', $id)
    ->first();

print_r($user);

6. Query several rows

$activeUsers = $database->table('users')
    ->where('active', 1)
    ->orderBy('name')
    ->limit(20)
    ->get();

print_r($activeUsers);

7. Update

$database->table('users')
    ->where('id', $id)
    ->update(['name' => 'Updated User']);

8. Raw parameterized SQL

$rows = $database->select(
    'SELECT * FROM users WHERE active = ?',
    [1]
);

Keep user values in bindings. Do not concatenate untrusted values into SQL.

9. Transactions

$database->transaction(function ($db) {
    $db->table('users')->insert([
        'name' => 'Transactional User',
        'email' => 'transaction@example.com',
        'active' => true,
    ]);
});

10. Delete the test row

$database->table('users')
    ->where('id', $id)
    ->delete();

11. Multiple connections and diagnostics

DatabaseManager supports named connections and Prefab diagnostics. Start with one PDO connection and add named connections only when your application needs them.

What Database provides

Prefab keeps database access lightweight: PDO connections, parameterized SQL, transactions and a query builder. Your application keeps control of its tables and schema.
