Database

Create a real tutorial table, then test connections, the query builder, raw SQL, transactions, multiple connections, runtime connection management and diagnostics.

Install

composer require tihloh/prefab-database

Create the tutorial database

Create a MariaDB/MySQL database named prefab_tutorial, then run:

CREATE TABLE users (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(190) NOT NULL UNIQUE,
    active TINYINT(1) NOT NULL DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Create database-test.php

<?php
require __DIR__ . '/vendor/autoload.php';

use Tihloh\Prefab\Database\Services\DatabaseManager;

$database = new DatabaseManager([
    'connections' => [
        'main' => [
            'driver' => 'mysql',
            'host' => '127.0.0.1',
            'database' => 'prefab_tutorial',
            'username' => 'root',
            'password' => '',
        ],
    ],
]);

var_dump($database->ping('main'));
php database-test.php

Insert

$id = $database->table('users')->insertGetId([
    'name' => 'Demo User',
    'email' => 'demo@example.com',
    'active' => true,
]);
echo "Inserted ID: {$id}";

Select

$user = $database->table('users')->where('id', $id)->first();
print_r($user);

$active = $database->table('users')
    ->where('active', true)
    ->orderBy('name')
    ->limit(20)
    ->get();
print_r($active);

Update

$database->table('users')->where('id', $id)->update([
    'name' => 'Updated Demo User',
]);

Delete

$database->table('users')->where('id', $id)->delete();

Raw SQL

$rows = $database->select(
    'SELECT * FROM users WHERE active = ?',
    [1],
);
print_r($rows);

$database->statement(
    'UPDATE users SET active = ? WHERE email = ?',
    [false, 'demo@example.com'],
);

Transactions

$database->transaction(function ($db) {
    $db->table('users')->insert([
        'name' => 'Transactional User',
        'email' => 'transaction@example.com',
    ]);
});

Use an existing PDO connection

$pdo = new PDO(
    'mysql:host=127.0.0.1;dbname=prefab_tutorial;charset=utf8mb4',
    'root',
    '',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

$database = new DatabaseManager([
    'connections' => ['main' => $pdo],
]);

Multiple connections

$database = new DatabaseManager([
    'default' => 'main',
    'connections' => [
        'main' => $pdo,
        'logs' => [
            'driver' => 'sqlite',
            'database' => __DIR__ . '/storage/logs.sqlite',
        ],
    ],
]);

$main = $database->connection('main');
$logs = $database->connection('logs');

Query a named connection

$rows = $database
    ->table('prefab_logs', 'logs')
    ->orderBy('id', 'desc')
    ->limit(20)
    ->get();

Raw PDO escape hatch

$pdo = $database->connection('main');
$defaultPdo = $database->pdo();

Runtime connection management

echo $database->defaultName();
print_r($database->names());
var_dump($database->has('main'));
echo $database->driver('main');
var_dump($database->ping('main'));

$database->set('archive', $archivePdo);
$database->useDefault('archive');

Shared database contract

Other Prefab modules can consume the small DatabaseInterface capability rather than requiring the whole Database package. Plain PDO is adapted automatically, so modules can stay standalone.

Configuration precedence

Direct module instance
    ↓
Module-specific PrefabConfig
    ↓
Common PrefabConfig
    ↓
Auto-discovered database capability
    ↓
Default / clear error

Diagnostics

print_r($database->explain());

When using broader Prefab configuration, you can also inspect runtime capability resolution with PrefabRuntime::inspect().

Checkpoint: you can create, read, update and delete a real row; run raw SQL and a transaction; inspect connections; and switch between named connections without undefined setup.
