Database

Connect to MariaDB/MySQL, perform CRUD, use raw SQL and transactions, then inspect an operation with Prefab tracing.

1. Install

composer require tihloh/prefab-database

2. Create a table

CREATE TABLE users (
id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
name VARCHAR(100) NOT NULL,
email VARCHAR(190) NOT NULL UNIQUE,
active TINYINT(1) NOT NULL DEFAULT 1
);

3. Connect

use Tihloh\Prefab\Database\Services\DatabaseManager;
$database = new DatabaseManager([
'connections' => ['main' => [
'driver' => 'mysql', 'host' => '127.0.0.1',
'database' => 'prefab_tutorial', 'username' => 'root', 'password' => '',
]],
]);
var_dump($database->ping('main'));

4. Insert and read

$id = $database->table('users')->insertGetId([
'name' => 'Demo User', 'email' => 'demo@example.com', 'active' => true,
]);
$user = $database->table('users')->where('id', $id)->first();

5. Update and delete

$database->table('users')->where('id', $id)->update(['name' => 'Updated User']);
$database->table('users')->where('id', $id)->delete();

6. Raw SQL

$rows = $database->select('SELECT * FROM users WHERE active = ?', [1]);
$database->statement('UPDATE users SET active = ? WHERE email = ?', [false, 'demo@example.com']);

Keep values in bindings instead of concatenating untrusted input into SQL.

7. Transactions

$database->transaction(function ($db) {
    $db->table('users')->insert(['name' => 'Transactional User', 'email' => 'transaction@example.com']);
});

8. Developer tip: trace a database operation

$rows = $database->table('users')->where('active', true)->get();

prefab_trace();

Detailed mode:

prefab_trace(true);

The Database module traces safe summaries such as table/operation and binding counts rather than exposing bound secret values.

9. Multiple connections and diagnostics

print_r($database->names());
echo $database->defaultName();
print_r($database->explain());
