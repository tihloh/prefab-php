Troubleshooting

PHP is not recognized

Windows
where.exe php
$env:Path

Confirm the PHP directory is in PATH, then reopen PowerShell.

Linux
which php
php -v

If missing on Ubuntu/Debian, install php-cli.

Composer is not recognized

Windows
where.exe composer
composer --version
Linux
which composer
composer --version

Missing PDO driver

php -m

For MariaDB/MySQL, verify PDO and pdo_mysql are listed.

Minimum-stability error

If a Prefab package has not yet received a stable release, development testing may require an explicit version:

composer require tihloh/prefab-routes:dev-main

Auto-wiring did not resolve a module

print_r($auth->explain());
print_r($users->explain());

Check explicit configuration first, then shared configuration, installed compatible modules and required database/session resources.
