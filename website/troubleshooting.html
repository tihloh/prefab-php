Troubleshooting

When a problem depends on your operating system, use the Windows/Linux tabs. Your selected operating system is remembered on the other tutorial pages.

PHP is not recognized

Windows
where.exe php
$env:Path

Confirm the PHP directory is in PATH, then close PowerShell and open a new PowerShell window before testing again.

Linux
which php
php -v

If PHP is missing on Ubuntu/Debian, install php-cli and the extensions listed in the installation guide.

Composer is not recognized

Windows
where.exe composer
composer --version

If Composer was just installed, close PowerShell and open it again so Windows reloads PATH.

Linux
which composer
composer --version

If Composer is missing, return to the installation guide and complete the Composer installation steps.

Missing PDO driver

php -m

For MariaDB/MySQL, verify both PDO and pdo_mysql are listed. Make sure you are checking the same CLI PHP installation Composer uses.

Composer cannot install a Prefab package

First confirm the package name is typed exactly as shown in the tutorial and that Composer itself works:

composer --version
composer require tihloh/prefab-routes

Do not change minimum-stability or switch the tutorial to a development branch. The tutorial assumes the normal stable Prefab packages.

Auto-wiring did not resolve a module

print_r($auth->explain());
print_r($users->explain());

Check explicit configuration first, then shared configuration, installed compatible modules and required database/session resources.
