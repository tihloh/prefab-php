Environment & .env

Prefab Core can load project environment values without requiring another dotenv package.

1. Create .env

APP_ENV=development
DB_HOST=127.0.0.1
DB_PORT=3306
DEBUG=true

2. Read values

$host = prefab_env('DB_HOST');
$port = prefab_env('DB_PORT', 3306);
$debug = prefab_env('DEBUG', false);

Use prefab_env() as the collision-safe Prefab helper. Loaded values are also available through normal process environment access such as getenv() and $_ENV.

3. Existing values win

Prefab does not overwrite environment variables already supplied by the operating system, web server or hosting platform unless explicit override behavior is requested through the underlying API.

4. Explicit loading

use Tihloh\Prefab\Core\Environment\Env;

Env::load(__DIR__ . '/../.env');
Tip: Prefer Prefab-prefixed global helpers in reusable applications to avoid collisions with project or framework helper names.
