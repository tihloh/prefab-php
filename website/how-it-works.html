Introduction

How Prefab works

Prefab keeps modules independent, then lets compatible modules cooperate through shared capabilities.

Independent modules

Routes can work without Users. Users can work without Auth. Permissions can work with Prefab Users or another user system.

Capabilities

Modules may publish resources such as database, user provider, group provider, logger or current actor.

Auto-discovery

A compatible consumer can discover a capability instead of forcing repetitive manual wiring.

Explicit still wins

Module-specific configuration and adapters override automatic defaults.

No hidden business logic

Infrastructure may auto-connect; your application still decides what actions should happen.

Framework-independent

Plain PHP is the baseline; Laravel and other frameworks integrate through adapters.

Resolution order

Explicit module configuration
          ↓
Shared Prefab configuration
          ↓
Compatible discovered capability
          ↓
Safe internal default
          ↓
Clear error when a required resource is unavailable
Developer-facing rule: if Prefab can safely resolve something itself, normal application code should not need to call internal configuration methods.
