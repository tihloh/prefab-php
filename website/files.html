Files

The Files module gives application code one API for storing, reading and moving files without tying the rest of the application to one physical folder. This tutorial starts with local private storage, then adds public files, uploads, collision rules, streams and temporary downloads.

1. Install Files

composer require tihloh/prefab-files

2. Create private and public storage folders

mkdir storage
mkdir storage/private
mkdir public/uploads

storage/private sits outside the web document root, so files placed there cannot normally be requested directly by URL. public/uploads is intentionally browser-accessible.

This distinction matters because not every uploaded document should be public. A private report may require an authorization check before the application sends it to a user.

3. Configure storage disks

Create public/files.php and begin with:

<?php
require __DIR__ . '/../vendor/autoload.php';

use Tihloh\Prefab\Files\FileManager;

$files = new FileManager([
    'default' => 'private',
    'disks' => [
        'private' => [
            'driver' => 'local',
            'root' => __DIR__ . '/../storage/private',
        ],
        'public' => [
            'driver' => 'local',
            'root' => __DIR__ . '/uploads',
            'url' => '/uploads',
        ],
    ],
]);

A disk is a named storage destination. The application talks to the disk name instead of hard-coding physical paths everywhere. Both disks in this tutorial use the local driver, but they have different roots and visibility.

The default disk is used when an operation does not explicitly name a disk. Here, storage is private by default, which is safer for application documents.

4. Store one file

$info = $files->put(
    'documents/demo.txt',
    'Hello Prefab'
);

echo $info->path();

The path documents/demo.txt is relative to the disk root. Prefab combines the disk root and relative path internally. Application code therefore does not need to know whether the disk lives in C:\..., /srv/..., or another storage backend.

Checkpoint: storage/private/documents/demo.txt should exist and contain Hello Prefab.

5. Read and inspect the file

echo $files->read('documents/demo.txt');

$info = $files->info('documents/demo.txt');
print_r($info->toArray());

read() returns the contents. info() returns metadata about the stored file, which is useful when building file lists or download screens.

echo $info->name();
echo $info->extension();
echo $info->size();
echo $info->mime();
echo $info->checksum();

The checksum is a content fingerprint. It can be used to detect whether a file changed or to compare two files without reading them byte-for-byte in application code.

6. Add browser controls

Add a POST handler so the page can create, copy, move and delete files:

$message = '';

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $action = $_POST['action'] ?? 'put';
    $path = trim($_POST['path'] ?? 'documents/demo.txt');

    if ($action === 'put') {
        $info = $files->put($path, $_POST['contents'] ?? 'Hello Prefab');
        $message = 'Stored: ' . $info->path();
    }
    if ($action === 'copy') {
        $files->copy($path, 'copies/' . basename($path));
        $message = 'Copied.';
    }
    if ($action === 'move') {
        $files->move($path, 'moved/' . basename($path));
        $message = 'Moved.';
    }
    if ($action === 'delete') {
        $files->delete($path);
        $message = 'Deleted.';
    }
}

$list = $files->files('', recursive: true);

copy() leaves the original in place. move() changes its location. delete() removes it. files('', recursive: true) scans the disk and returns files from nested directories as well.

Add the form:

<h1>Prefab Files Test</h1>
<p><?= htmlspecialchars($message) ?></p>
<form method="post">
    <p><input name="path" value="documents/demo.txt" size="40"></p>
    <p><textarea name="contents" rows="5" cols="50">Hello Prefab</textarea></p>
    <button name="action" value="put">Store / overwrite</button>
    <button name="action" value="copy">Copy</button>
    <button name="action" value="move">Move</button>
    <button name="action" value="delete">Delete</button>
</form>

Display the current contents of the disk:

<h2>Stored files</h2>
<pre><?php
foreach ($list as $file) {
    echo $file->path() . ' (' . $file->size() . " bytes)\n";
}
?></pre>
Checkpoint: Store a file, copy it, move one copy, and delete another. The list should reflect each operation.

7. Decide what happens when a path already exists

$files->put('reports/report.txt', 'A', ['collision' => 'overwrite']);
$files->put('reports/report.txt', 'B', ['collision' => 'skip']);
$files->put('reports/report.txt', 'C', ['collision' => 'rename']);
$files->put('reports/report.txt', 'D', ['collision' => 'error']);

A collision policy makes duplicate-path behavior explicit. overwrite replaces the existing file, skip keeps it unchanged, rename stores the new file under another available name, and error rejects the operation.

8. Work with directories

$files->makeDirectory('documents/2026');
$files->directoryExists('documents/2026');
$files->directories('documents');
$files->directories('documents', recursive: true);
$files->files('documents');
$files->files('documents', recursive: true);
$files->deleteDirectory('documents/old');
$files->deleteDirectory('temporary/import-1', recursive: true);

Directory methods are useful for organizing user uploads, imports, report years or other logical groups. Recursive operations include nested folders.

9. Advanced: streams and existing files

$stream = fopen($sourcePath, 'rb');
try {
    $files->putStream('archives/backup.zip', $stream);
} finally {
    fclose($stream);
}

$files->putFile('/tmp/report.pdf', 'reports/report.pdf');
$stream = $files->readStream('archives/backup.zip');

Streams are useful for large files because the application can process data incrementally instead of loading the entire file into memory.

10. Advanced: storage usage

$files->checksum('documents/demo.txt');
$files->checksum('documents/demo.txt', 'sha512');
$files->size('documents/demo.txt');
$files->directorySize('documents');
$files->usage();

These methods help build storage quotas, administration pages and integrity checks.

11. Public files and URLs

$files->put('demo.txt', 'Public file', 'public');
echo $files->url('demo.txt', 'public');

The public disk has a URL base, so Prefab can turn a storage path into a browser URL. The private disk does not expose a normal public URL because access should go through application logic instead.

print_r($files->names());
echo $files->defaultName();
var_dump($files->hasDisk('public'));
$files->useDefault('public');

12. Validate uploads before storing them

An uploaded file is still user input. Validate it before it reaches permanent storage. Install Prefab Input if it is not already present:

composer require tihloh/prefab-input

The HTML form must use multipart/form-data; without that encoding, the browser does not send file contents correctly.

<form method="post" enctype="multipart/form-data">
    <input type="file" name="document" required>
    <button>Upload</button>
</form>
$result = Input::fromRequest()->process([
    'document' => 'required|file|mimes:pdf|max_size:20mb',
]);

if ($result->passes()) {
    $stored = $files->storeUploaded(
        $result->validated('document'),
        'documents',
    );

    print_r($stored->toArray());
}

The flow is deliberate: browser upload → Input validation → Files storage. Files should not have to decide whether the uploaded PDF is acceptable business input.

13. Advanced: capabilities and hooks

var_dump($files->supports('checksum'));
var_dump($files->supports('atomic_write'));
var_dump($files->supports('public_url', 'public'));

$files->on('stored', function ($file, $disk, $context) {
    echo 'Stored: ' . $file->path();
});

Capabilities let code ask what a disk supports before using an optional feature. Hooks let the application react to file events without putting unrelated behavior directly inside the storage operation.

14. Advanced: temporary URLs and downloads

$url = $files->temporaryUrl('documents/private.pdf', 600);

A temporary URL grants time-limited access to a private path. The lifetime here is 600 seconds.

$valid = $files->verifyTemporaryUrl(
    $_GET['path'] ?? '',
    (int) ($_GET['expires'] ?? 0),
    $_GET['signature'] ?? '',
    $_GET['disk'] ?? null,
);

The signature prevents someone from simply changing the path or expiry value in the URL.

$download = $files->download(
    'documents/report.pdf',
    'Annual Report.pdf'
);
print_r($download->headers());

The download helper describes how a file should be returned to the client, including download-related headers and the user-facing filename.
