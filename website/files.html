Files

Store, read, list and manage files without tying application code to one physical folder.

1. Install

composer require tihloh/prefab-files

2. Configure disks

use Tihloh\Prefab\Files\FileManager;
$files = new FileManager([
'default' => 'private',
'disks' => [
'private' => ['driver' => 'local', 'root' => __DIR__ . '/../storage/private'],
'public' => ['driver' => 'local', 'root' => __DIR__ . '/uploads', 'url' => '/uploads'],
],
]);

3. Store and read

$info = $files->put('documents/demo.txt', 'Hello Prefab');
echo $files->read('documents/demo.txt');
echo $info->path();

4. List and manage

$list = $files->files('', recursive: true);
$files->copy('documents/demo.txt', 'copies/demo.txt');
$files->move('copies/demo.txt', 'moved/demo.txt');
$files->delete('moved/demo.txt');
<ul>
<?php foreach ($list as $file): ?>
<li><?= htmlspecialchars($file->path()) ?> (<?= $file->size() ?> bytes)</li>
<?php endforeach; ?>
</ul>
Checkpoint: Stored files appear in the visible list and copy/move/delete change the list.

5. Collision policies

$files->put('report.txt', 'A', ['collision' => 'overwrite']);
$files->put('report.txt', 'B', ['collision' => 'skip']);
$files->put('report.txt', 'C', ['collision' => 'rename']);
$files->put('report.txt', 'D', ['collision' => 'error']);

6. Validate uploads before storage

$result = Input::fromRequest()->process([
'document' => 'required|file|mimes:pdf|max_size:20mb',
]);
if ($result->passes()) {
    $stored = $files->storeUploaded($result->validated('document'), 'documents');
}

7. Public and private delivery

$files->put('demo.txt', 'Public file', 'public');
echo $files->url('demo.txt', 'public');
$url = $files->temporaryUrl('documents/private.pdf', 600);

8. Developer tip: trace a file operation

$info = $files->put('documents/demo.txt', 'Hello Prefab');

prefab_trace();

Detailed mode:

prefab_trace(true);

Tracing is optional developer diagnostics. Keep the file list/status as the normal application result.

9. Streams and storage information

$stream = $files->readStream('archives/backup.zip');
$files->checksum('documents/demo.txt');
$files->directorySize('documents');
$files->usage();
