Files

Keep upload validation separate from file storage and file-management concerns.

Install

composer require tihloh/prefab-files

Recommended flow

Browser upload
     ↓
Prefab Input validates metadata/rules
     ↓
Accepted upload
     ↓
Prefab Files stores/manages it
     ↓
Your application saves any business reference

Do not rely on the original filename alone. Validate file size/type before storing, and keep public/private storage decisions explicit.

Checkpoint: accept one valid upload, reject an invalid one, and verify the stored file path returned by your storage configuration.
