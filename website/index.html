Introduction

Reusable PHP building blocks without adopting a full framework.

Prefab PHP is a family of small, framework-independent Composer packages for common application features such as routing, users, authentication, permissions, logs, files and messaging.

ModularReusableIndependentAdaptiveBetter Together
Prefab is not a framework. It does not take ownership of your project structure, controllers, templates or business logic. Install only the modules you need and keep writing normal PHP.

What problem does Prefab solve?

Plain PHP gives you freedom, but common features often require repeating the same plumbing: database access, user lookups, password login, session handling, permission checks, logs and integration code. Prefab packages provide reusable implementations without requiring you to rebuild the whole application around them.

Each module should remain useful on its own. When a compatible module becomes available, it can enhance another module without turning into a hard dependency.

Who is this tutorial for?

This tutorial assumes basic plain-PHP knowledge: variables, arrays, functions, classes, forms, require, and simple database concepts. It does not assume Laravel, Symfony, advanced Composer knowledge, or Linux-only development.

Windows and Linux are both supported throughout the tutorial. When commands differ, PowerShell and Linux examples are shown separately. Common PHP and Composer commands are shown once.
