Audit Logs

Record application activity and show it in a table an administrator can read.

1. Install

composer require tihloh/prefab-logs

2. Start Logs

use Tihloh\Prefab\Logs\Services\LogManager;
$logs = new LogManager();

3. Record an event

$entry = $logs->record([
'action' => 'document.approved',
'subject_type' => 'document',
'subject_id' => 1001,
'actor_id' => 1,
'message' => 'Document was approved.',
]);

4. Show recent activity

$recent = $logs->recent(20);
?>
<table border="1" cellpadding="8">
<tr><th>Action</th><th>Subject</th><th>Actor</th><th>Message</th></tr>
<?php foreach ($recent as $log): ?>
<tr><td><?= htmlspecialchars($log['action']) ?></td><td><?= htmlspecialchars($log['subject_type']) ?> #<?= $log['subject_id'] ?></td><td><?= $log['actor_id'] ?? 'System' ?></td><td><?= htmlspecialchars($log['message'] ?? '') ?></td></tr>
<?php endforeach; ?>
</table>
Checkpoint: The recorded event appears as a normal activity row.

5. Query useful history

$logs->recent(50);
$logs->forSubject('document', 1001);
$logs->forActor(1);

6. Structured changes

$logs->record([
'action' => 'user.updated',
'subject_type' => 'user',
'subject_id' => 25,
'actor_id' => 7,
'changes' => ['office' => ['old' => 'Accounting', 'new' => 'Budget']],
]);

7. Developer tip: trace the operation

$entry = $logs->record($data);

prefab_trace();

Detailed mode:

prefab_trace(true);

prefab_trace() is temporary developer diagnostics. Prefab Logs is persistent application/audit history; they serve different purposes.

8. Configuration diagnostics

print_r($logs->explain());
