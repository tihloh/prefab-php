Audit Logs

Record application activity and show it in a simple table an administrator can actually read.

1. Install Logs

composer require tihloh/prefab-logs

2. Start Logs

use Tihloh\Prefab\Logs\Services\LogManager;

$logs = new LogManager();

Logs can reuse the shared Prefab database automatically.

3. Record an event

$logs->record([
    'action' => 'document.approved',
    'subject_type' => 'document',
    'subject_id' => 1001,
    'actor_id' => 1,
    'message' => 'Document was approved.',
]);

4. Load recent activity

$recent = $logs->recent(20);

5. Display the activity

Audit records naturally fit a table:

<h2>Recent activity</h2>

<table border="1" cellpadding="8">
    <tr>
        <th>Action</th><th>Subject</th><th>Actor</th><th>Message</th>
    </tr>
    <?php foreach ($recent as $log): ?>
    <tr>
        <td><?= htmlspecialchars($log['action']) ?></td>
        <td><?= htmlspecialchars($log['subject_type']) ?> #<?= $log['subject_id'] ?></td>
        <td><?= $log['actor_id'] ?? 'System' ?></td>
        <td><?= htmlspecialchars($log['message'] ?? '') ?></td>
    </tr>
    <?php endforeach; ?>
</table>
Checkpoint: You should see “Document was approved.” as a row in the activity table.

6. Query useful history

$logs->recent(50);
$logs->forSubject('document', 1001);
$logs->forActor(1);

forSubject() answers “what happened to this record?” while forActor() answers “what did this user do?”

7. Human-friendly labels

$activity = $logs->humanRecent(
    20,
    actorResolver: fn ($id) => "User #{$id}",
    subjectResolver: fn ($type, $id) => "{$type} #{$id}",
);

Use the returned labels in the same table when you want names instead of raw IDs.

8. Store structured changes

$logs->record([
    'action' => 'user.updated',
    'subject_type' => 'user',
    'subject_id' => 25,
    'actor_id' => 7,
    'changes' => [
        'office' => ['old' => 'Accounting', 'new' => 'Budget'],
    ],
]);

9. Automatic logging

$logs = new LogManager();
$users = new UserManager(['database' => $pdo]);

$users->create([
    'name' => 'Alice',
    'email' => 'alice@example.com',
]);

Compatible modules can send their activity to Logs automatically.

10. Developer tip

print_r($logs->explain());

Use diagnostics only while debugging. The normal visible result is the activity table.
