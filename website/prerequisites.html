Getting Started

Minimum prerequisites

You only need a basic plain-PHP background. This page checks the minimum environment before Prefab is introduced.

PHP 8.1+

Current Prefab packages target PHP 8.1 or newer.

Composer 2

Installs packages and generates the autoloader.

Editor

VS Code, PhpStorm, Notepad++ or any plain-text code editor.

Terminal

PowerShell/CMD on Windows or a shell on Linux.

PDO

Required for database-backed sections.

Basic PHP

Variables, arrays, functions, classes, forms and require.

Verify your machine

These commands work on both Windows and Linux:

php -v
composer --version
php -m

Look for PDO. For MariaDB/MySQL examples, also look for pdo_mysql.

Do not continue if PHP or Composer is not recognized. Fix the CLI setup first; the next page shows both Windows and Linux installation paths.
