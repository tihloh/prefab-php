Getting Started

Install PHP and Composer

This page assumes you have never installed PHP or Composer before. Follow only the section for your operating system and do not continue until every verification step works.

What are we installing?

PHP runs your PHP programs. Composer downloads PHP packages such as Prefab and creates the autoloader used by your project. Composer needs a working PHP installation, so PHP must be installed and verified first.

Choose your operating system

If you use Windows, follow Windows. If your server or computer uses Ubuntu or Debian Linux, follow Linux. Commands shown in one section should not be copied into the other operating system.

Windows — from a computer with no PHP

Windows

Step 1 — Check whether PHP is already installed

Open the Start menu, type PowerShell, and open Windows PowerShell or Terminal. Type:

php -v

If you see a PHP version such as PHP 8.1, PHP 8.2, PHP 8.3 or newer, PHP is already available. Prefab requires PHP 8.1 or newer. You may skip to Step 4.

If PowerShell says that php is not recognized, PHP is either not installed or its folder is not in Windows PATH. Continue below.

Step 2 — Install PHP

For a beginner development computer, a PHP development stack such as Laragon or XAMPP is often easier because it can provide PHP and a local database together. A standalone PHP installation also works. Whichever method you choose, make sure the installed PHP version is 8.1 or newer.

Do not install several PHP packages just to follow this tutorial. Use one PHP installation and learn where its php.exe is located.

Typical examples of PHP folders are:

C:\laragon\bin\php\php-8.x.x\
C:\xampp\php\
C:\php\

Your actual folder may be different. Open it in File Explorer and confirm that php.exe exists.

Step 3 — Add PHP to Windows PATH

PATH lets you type php from any folder instead of typing the full location of php.exe.

  1. Copy the folder containing php.exe. Copy the folder path, not php.exe itself.
  2. Open Start and search for environment variables.
  3. Open Edit the system environment variables.
  4. Click Environment Variables.
  5. Under your user variables, select Path and click Edit.
  6. Click New and paste the PHP folder.
  7. Click OK on the open dialogs.
  8. Close PowerShell and open a new PowerShell window. Existing terminals do not automatically receive the changed PATH.

Now verify:

php -v
where.exe php

php -v must show PHP 8.1 or newer. where.exe php shows which php.exe Windows is actually using.

Checkpoint: Do not continue until php -v works from a newly opened PowerShell window.

Step 4 — Check the PHP extensions Prefab examples need

Run:

php -m | findstr /I "PDO pdo_mysql mbstring openssl"

For the MySQL/MariaDB examples in this tutorial, you should have PDO and pdo_mysql. mbstring and openssl are also commonly needed by PHP applications and Composer packages.

If pdo_mysql is missing, find the configuration file PHP is using:

php --ini

Open the reported php.ini. Depending on the PHP distribution, ensure the PDO MySQL extension is enabled. After changing PHP configuration, close and reopen PowerShell and run the extension check again.

Step 5 — Install Composer on Windows

Download and run the official Composer-Setup.exe installer from Composer. During installation it may ask for the PHP executable. Select the same php.exe that worked in the previous steps.

Finish the installer, then close PowerShell and open it again. Verify:

composer --version
where.exe composer

You should see a Composer 2.x version. If composer is not recognized, reopen the terminal first. If it still fails, check that Composer was added to PATH by its installer.

Step 6 — Final Windows test

Create a temporary folder and confirm that PHP and Composer work outside their installation directories:

cd $HOME
mkdir prefab-test
cd prefab-test
php -r "echo 'PHP works';"
composer --version

If the terminal prints PHP works and a Composer version, your Windows command-line environment is ready.

Linux — Ubuntu / Debian from a computer with no PHP

Linux

Step 1 — Open a terminal and check PHP

php -v

If PHP 8.1 or newer is already installed, continue to the extension checks. If the command is not found, install PHP below.

Step 2 — Update the package list

sudo apt update

sudo runs the command with administrator privileges. Linux may ask for your account password. When typing the password, the terminal normally shows no characters; type it and press Enter.

Step 3 — Install PHP and common extensions

sudo apt install php-cli php-mysql php-mbstring php-xml php-curl unzip curl

When apt asks whether to continue, type Y and press Enter. Then verify:

php -v
which php
php -m | grep -Ei 'PDO|pdo_mysql|mbstring|openssl'

php -v must report PHP 8.1 or newer. which php normally reports a path such as /usr/bin/php.

Checkpoint: Do not install Composer until php -v works and reports PHP 8.1 or newer.

Step 4 — Install Composer

Composer can be installed using its official installer. Run these commands one at a time:

cd ~
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
php composer-setup.php
php -r "unlink('composer-setup.php');"
sudo mv composer.phar /usr/local/bin/composer

Then verify:

composer --version
which composer

You should see Composer 2.x and a location such as /usr/local/bin/composer.

Security note: Composer publishes an installer-signature verification procedure on its official download page. For production or security-sensitive machines, follow the current official verification instructions before running the installer.

Step 5 — Final Linux test

cd ~
mkdir -p prefab-test
cd prefab-test
php -r "echo 'PHP works';"
composer --version

If both commands work, the Linux command-line environment is ready.

Understand what the commands mean

A new student should know what was just installed:

CommandMeaning
php -vShows the PHP command-line version.
php -mLists enabled PHP extensions.
where.exe phpWindows: shows which PHP executable will run.
which phpLinux: shows which PHP executable will run.
composer --versionChecks that Composer is installed and accessible.
PDOPHP's common database access interface.
pdo_mysqlPDO driver used to connect to MySQL/MariaDB.
PATHFolders the operating system searches when you type a command.

Common beginner problems

“php is not recognized” on Windows

PHP's folder is not in PATH, the PATH points to the wrong folder, or the terminal was opened before PATH was changed. Run where.exe php after opening a new PowerShell window.

“composer is not recognized” on Windows

Close and reopen PowerShell after installing Composer. Then run where.exe composer.

Composer uses the wrong PHP version

Check php -v and the PHP path. Multiple PHP installations can cause confusion. The command-line PHP is the one that matters to Composer.

pdo_mysql is missing

Windows users should check the active php.ini using php --ini. Ubuntu/Debian users can install the MySQL extension with sudo apt install php-mysql.

My browser can open PHP, but php -v fails

Your web server may know where PHP is while your terminal does not. This tutorial uses Composer and PHP's development server from the terminal, so command-line PHP must work too.
