Getting Started

Install PHP and Composer

Choose the instructions for your operating system. Once installed, the rest of the tutorial uses the same PHP code on both platforms.

Windows

PowerShell

You may use PHP from XAMPP, Laragon, or a standalone PHP installation. Add its PHP directory to Windows PATH, open a new PowerShell window, then verify:

php -v
where.exe php

Install Composer for Windows and let the installer use the same PHP executable. Then:

composer --version
where.exe composer
php -m | findstr /I "PDO pdo_mysql"
Linux

Ubuntu / Debian

sudo apt update
sudo apt install php-cli php-mysql php-mbstring php-xml unzip curl
php -v
which php

Install Composer using the official Composer installer or your distribution package, then verify:

composer --version
which composer
php -m | grep -Ei 'PDO|pdo_mysql'
CLI PHP matters. Apache/Nginx can use a different PHP installation. Composer and php -S use the PHP shown by your terminal.
