Getting Started

Install PHP and Composer

This page assumes you have never installed PHP or Composer before. Choose your operating system below. Your choice is remembered across the tutorial.

What are we installing?

PHP runs your PHP programs. Composer downloads PHP packages such as Prefab and creates the autoloader used by your project. Composer needs a working PHP installation, so PHP must be installed and verified first.

Windows

These instructions use PowerShell. Follow the steps in order even if this is the first time you have installed PHP.

Download PHP ↗PHP Windows guide ↗PHP CLI guide ↗Download Composer ↗Composer Windows guide ↗

Step 1 — Check whether PHP is already installed

Open the Start menu, type PowerShell, then open Windows PowerShell or Terminal. Type:

php -v

If you see PHP 8.1 or newer, PHP is already available and you can continue to Step 4. If Windows says php is not recognized, continue to Step 2.

Step 2 — Install PHP

Download PHP from the official Windows download page above. For command-line use, PHP's documentation recommends a Non-Thread-Safe build. Use a supported PHP version newer than the Prefab minimum of PHP 8.1.

Use one PHP installation. Installing several PHP copies can make Composer use a different PHP version from the one you expect.

Extract PHP to a simple folder such as:

C:\php\

Open the folder in File Explorer and make sure php.exe is there.

Step 3 — Add PHP to Windows PATH

PATH lets Windows find PHP when you type php in any folder.

  1. Copy the folder path that contains php.exe.
  2. Open Start and search for environment variables.
  3. Open Edit the system environment variables.
  4. Click Environment Variables.
  5. Under your user variables, select Path, then click Edit.
  6. Click New and paste the PHP folder.
  7. Click OK on all dialogs.
  8. Close PowerShell completely and open a new PowerShell window.

Verify:

php -v
where.exe php
Checkpoint: php -v must show PHP 8.1 or newer before you continue.

Step 4 — Check required PHP extensions

php -m | findstr /I "PDO pdo_mysql mbstring openssl"

For the MySQL/MariaDB examples you should see PDO and pdo_mysql. If pdo_mysql is missing, first find the active configuration file:

php --ini

Open the reported php.ini, enable the PDO MySQL extension, reopen PowerShell, then run the extension check again.

Step 5 — Install Composer

Open the official Composer download page above and download Composer-Setup.exe. Run it and choose the same php.exe verified above if the installer asks. Close PowerShell after installation and open it again.

composer --version
where.exe composer

You should see Composer 2.x and the Composer executable location.

Step 6 — Final test

cd $HOME
mkdir prefab-test
cd prefab-test
php -r "echo 'PHP works';"
composer --version
php -m | findstr /I "PDO pdo_mysql"
Ready when: PHP is 8.1+, Composer reports a version, and PDO/pdo_mysql are enabled.
Linux

These instructions target Ubuntu/Debian and use the apt package manager.

PHP install manual ↗Composer installer ↗Composer Linux guide ↗

Step 1 — Check whether PHP is already installed

php -v

If PHP 8.1 or newer is already installed, continue to Step 3. If the command is not found, continue below.

Step 2 — Install PHP from the terminal

You do not need to download a PHP ZIP manually on Ubuntu/Debian. Install the CLI and extensions with:

sudo apt update
sudo apt install php-cli php-mysql php-mbstring php-xml php-curl unzip curl

sudo runs a command with administrator privileges. Linux may ask for your account password and normally does not display characters while you type it. When apt asks whether to continue, type Y and press Enter.

Step 3 — Verify PHP and extensions

php -v
which php
php -m | grep -Ei 'PDO|pdo_mysql|mbstring|openssl'

php -v must report PHP 8.1 or newer. which php commonly shows /usr/bin/php.

Checkpoint: Do not install Composer until php -v works.

Step 4 — Install Composer

Composer's installer verification hash changes over time, so use the official Composer installer page linked above and copy its current verified installation commands rather than copying an old checksum from this tutorial. After it creates composer.phar, install it globally:

sudo mv composer.phar /usr/local/bin/composer
composer --version
which composer

Step 5 — Final test

cd ~
mkdir -p prefab-test
cd prefab-test
php -r "echo 'PHP works';"
composer --version
php -m | grep -Ei 'PDO|pdo_mysql'
Ready when: PHP is 8.1+, Composer reports a version, and PDO/pdo_mysql are enabled.

Understand the commands

CommandMeaning
php -vShows the command-line PHP version.
php -mLists enabled PHP extensions.
where.exe phpWindows: shows which PHP executable will run.
which phpLinux: shows which PHP executable will run.
composer --versionChecks that Composer is installed and accessible.
PDOPHP's common database access interface.
pdo_mysqlThe PDO driver used for MySQL and MariaDB.
PATHThe folders your operating system searches when you type a command.

If something does not work

If PHP or Composer is not recognized, do not continue to the next tutorial page. Recheck the executable location, reopen your terminal, and verify the commands shown in your selected operating-system tab.

Ready to continue: Once every final test in your selected tab works, continue to the next page.
