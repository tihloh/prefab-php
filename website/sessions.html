Session isolation

Every Prefab application should receive an isolated session identity by default, even when only one app currently exists on the server.

Why this matters

localhost/web1
localhost/web2

Plain PHP can otherwise use the same generic session cookie on the same host. Prefab's session-aware modules should separate these applications automatically.

Default behavior

localhost/web1
→ namespace: web1
→ cookie: PREFAB_WEB1_SESSION
→ cookie path: /web1

localhost/web2
→ namespace: web2
→ cookie: PREFAB_WEB2_SESSION
→ cookie path: /web2

If no session configuration exists, Prefab derives a stable application scope. Isolation is mandatory; configuration is optional.

Intentional sharing

PrefabConfig::set([
    'session' => [
        'namespace' => 'company_sso',
    ],
]);

Using the same explicit namespace in multiple apps indicates intentional sharing. Cookie path/domain rules still need to permit browser sharing.

No separate shared=true flag is required. An explicit common namespace already expresses that intention.
