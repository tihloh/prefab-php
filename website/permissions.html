Permissions

Authentication answers who the user is. Permissions answers what that user is allowed to do.

1. Install

composer require tihloh/prefab-permissions

2. Define permissions

<?php
return [
'documents.view' => ['name' => 'View Documents', 'default' => true],
'documents.approve' => ['name' => 'Approve Documents', 'default' => false],
];

3. Connect Permissions

$permissions = new PermissionManager(
    __DIR__ . '/../config/permissions.php',
    new PdoPermissionStore($pdo),
);

4. Check and change access

$allowed = $permissions->can($user, 'documents.approve');
$result = $permissions->resolve($user, 'documents.approve');
$permissions->set('user', 1, 'documents.approve', true);
$permissions->clear('user', 1, 'documents.approve');

5. Display effective permissions

$results = $permissions->resolvedFor($user);
?>
<table border="1" cellpadding="8">
<tr><th>Permission</th><th>Result</th><th>Source</th></tr>
<?php foreach ($results as $id => $result): ?>
<tr><td><?= htmlspecialchars($id) ?></td><td><?= $result->allowed ? 'ALLOW' : 'DENY' ?></td><td><?= htmlspecialchars($result->source) ?></td></tr>
<?php endforeach; ?>
</table>
Checkpoint: Change a permission and confirm the effective result/source changes.

6. Resolution order

User override
    ↓
Group overrides
    ↓
Definition default

7. Developer tip: trace a permission operation

$result = $permissions->resolve($user, 'documents.approve');

prefab_trace();

For detailed internal steps:

prefab_trace(true);

Tracing is optional developer output. Keep the effective-permissions table as the normal visible result.

8. Configuration diagnostics

print_r($permissions->explain());
