Getting Started

Create the tutorial project

This project will be reused by the module tutorials. You will create a normal Composer-based PHP application with a public web folder and a storage folder, then verify that Composer autoloading and the PHP development server both work.

1. Create the project folder

The project folder is the root of the application. Composer files, source code and private storage will live here. Only the public folder will be exposed by the web server.

Windows

PowerShell

mkdir prefab-tutorial
cd prefab-tutorial
composer init
mkdir public
mkdir storage
Linux

Bash

mkdir prefab-tutorial
cd prefab-tutorial
composer init
mkdir -p public storage

composer init creates composer.json. This file describes the PHP packages used by the application. The public folder will contain browser-accessible files such as index.php, CSS and JavaScript. The storage folder is for files that should not be directly accessible from the browser.

2. Install the first Prefab module

Prefab is modular, so there is no single framework package that installs everything. Each feature is installed only when the project needs it. Routes is the first module because it gives the application a way to decide which code should run for a requested URL.

composer require tihloh/prefab-routes

Composer downloads the package into vendor/, records the selected version in composer.lock, and updates composer.json. The vendor folder should not be edited manually because Composer owns it.

Checkpoint: The command should finish without errors and a vendor folder should exist.

3. Load Composer packages from PHP

Create public/index.php:

<?php

declare(strict_types=1);
require __DIR__ . '/../vendor/autoload.php';

echo 'Prefab is loaded';

The important line is require .../vendor/autoload.php. Composer generates this autoloader so PHP can find installed package classes automatically. Without it, classes from Prefab and other Composer packages would not be available to the application.

__DIR__ means “the directory containing this PHP file.” Because index.php is inside public, ../vendor/autoload.php moves one directory upward to the project root and then enters vendor.

4. Start the local web server

php -S 127.0.0.1:8000 -t public

php -S starts PHP's built-in development server. 127.0.0.1:8000 means the server is available only on the local computer at port 8000. -t public makes public the document root, so files outside it are not directly served to the browser.

Open http://127.0.0.1:8000. PHP automatically looks for index.php in the document root.

Checkpoint: If the browser displays Prefab is loaded, PHP, Composer, the autoloader and the local web server are all working.

5. Understand the starting structure

prefab-tutorial/
├─ composer.json
├─ composer.lock
├─ vendor/
├─ public/
│  └─ index.php
└─ storage/

This small structure is intentional. Later tutorials will add only the folders they need, such as config or routes. Keeping the first project small makes it easier to see what each module adds.
