Getting Started

Create the tutorial project

Windows

PowerShell

mkdir prefab-tutorial
cd prefab-tutorial
composer init
mkdir public
mkdir storage
Linux

Bash

mkdir prefab-tutorial
cd prefab-tutorial
composer init
mkdir -p public storage

Install the first module

Prefab modules are installed with Composer just like other PHP packages. For this tutorial, install Routes:

composer require tihloh/prefab-routes

Composer downloads the package and its dependencies into vendor/ and updates your project's composer.json and composer.lock. You do not need to add :dev-main or change Composer's minimum-stability.

Checkpoint: the command should finish successfully and vendor/ should exist. If Composer reports an error, stop here and fix the installation instead of continuing with a partially configured project.

Create public/index.php

<?php

declare(strict_types=1);
require __DIR__ . '/../vendor/autoload.php';

echo 'Prefab is loaded';

Run the local server

php -S 127.0.0.1:8000 -t public

Open http://127.0.0.1:8000.

Checkpoint: if you see “Prefab is loaded”, PHP, Composer, vendor/ and Composer autoloading are working.
