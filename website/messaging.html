Messaging

Start with a zero-cost local test channel so you can verify the complete send flow in a browser before configuring real SMTP.

Install

composer require tihloh/prefab-messaging

Create public/messaging.php

<?php
require __DIR__ . '/../vendor/autoload.php';

use Tihloh\Prefab\Messaging\Channels\CallableChannel;
use Tihloh\Prefab\Messaging\MessagingManager;
use Tihloh\Prefab\Messaging\Message;
use Tihloh\Prefab\Messaging\Recipient;

$messages = [];

$testChannel = new CallableChannel('test', function (Recipient $recipient, Message $message) use (&$messages) {
    $messages[] = [
        'recipient' => $recipient,
        'subject' => $message->subject,
        'text' => $message->text,
    ];
    return 'TEST-' . time();
});

$messaging = new MessagingManager([$testChannel]);
$result = null;

$messaging->on('sending', function () { /* before delivery */ });
$messaging->on('sent', function () { /* after success */ });
$messaging->on('failed', function () { /* after failure */ });

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $recipient = new Recipient([
        'test' => $_POST['to'] ?? 'demo@example.com',
    ]);

    $result = $messaging->send(
        'test',
        $recipient,
        new Message(
            $_POST['subject'] ?? 'Prefab test',
            $_POST['body'] ?? 'Hello from Prefab Messaging',
        ),
    );
}
?>
<!doctype html><html><body>
<h1>Prefab Messaging Test</h1>
<form method="post">
    <p><input name="to" value="demo@example.com"></p>
    <p><input name="subject" value="Prefab test"></p>
    <p><textarea name="body">Hello from Prefab Messaging</textarea></p>
    <button>Send test message</button>
</form>
<?php if ($result): ?>
    <h2>Delivery result</h2>
    <pre><?= htmlspecialchars(print_r($result, true)) ?></pre>
    <h2>Captured message</h2>
    <pre><?= htmlspecialchars(print_r($messages, true)) ?></pre>
<?php endif; ?>
</body></html>

This verifies channel registration, recipient routing, Message, send(), delivery results and lifecycle hooks without requiring an email account.

Direct mail API

$result = $messaging->mail(
    'user@example.com',
    'Annual Report',
    'Your report is ready.',
);

The mail() convenience requires a registered mail channel.

Real SMTP

use Tihloh\Prefab\Messaging\Channels\MailChannel;
use Tihloh\Prefab\Messaging\Mail\SmtpTransport;

$smtp = new SmtpTransport([
    'host' => 'smtp.example.com',
    'port' => 587,
    'username' => 'user@example.com',
    'password' => 'secret',
    'encryption' => 'tls',
    'from' => [
        'address' => 'noreply@example.com',
        'name' => 'My System',
    ],
]);

$messaging = new MessagingManager([
    new MailChannel($smtp),
]);

$result = $messaging->mail(
    'recipient@example.com',
    'SMTP Test',
    'This message was sent through SMTP.',
);

Generic channels

$result = $messaging->send(
    'sms',
    $recipient,
    new Message('OTP', 'Your code is 123456'),
);

Templates

$template = new Template(
    subject: 'Hello {{name}}',
    text: 'Your report {{report}} is ready.'
);

$message = $template->render([
    'name' => 'Demo User',
    'report' => 'AR-2026',
]);

Attachments

$message = new Message(
    subject: 'Report',
    text: 'Your report is attached.',
    attachments: [
        Attachment::fromPath('/tmp/report.pdf'),
    ],
);

You can also use Attachment::fromData() for in-memory content.

Delivery hooks

$messaging->on('sending', function ($channel, $recipient, $message) {});
$messaging->on('sent', function ($channel, $recipient, $message, $result) {});
$messaging->on('failed', function ($channel, $recipient, $message, $result) {});
Checkpoint: first verify sending through the local callable test channel. Only after that works, replace it with SMTP and confirm an external email arrives.
