Messaging

Send information outside the application. Start with a local test channel, build a small message form, then replace the test channel with real email when you are ready.

1. Install

composer require tihloh/prefab-messaging

2. Create a local test channel

<?php
require __DIR__ . '/../vendor/autoload.php';

use Tihloh\Prefab\Messaging\Channels\CallableChannel;
use Tihloh\Prefab\Messaging\MessagingManager;
use Tihloh\Prefab\Messaging\Message;
use Tihloh\Prefab\Messaging\Recipient;

$lastMessage = null;

$channel = new CallableChannel(
    'test',
    function (Recipient $recipient, Message $message) use (&$lastMessage) {
        $lastMessage = $message;
        return 'TEST-' . time();
    }
);

$messaging = new MessagingManager([$channel]);

The test channel does not contact an external provider. It lets you verify the application flow first.

3. Send one message

$recipient = new Recipient([
    'test' => 'demo@example.com',
]);

$result = $messaging->send(
    'test',
    $recipient,
    new Message('Prefab test', 'Hello from Prefab Messaging'),
);
Checkpoint: The send operation should succeed without sending a real email.

4. Add a message form

<form method="post">
    <input name="to" type="email" placeholder="Recipient" required>
    <input name="subject" placeholder="Subject" required>
    <textarea name="message" placeholder="Message" required></textarea>
    <button>Send</button>
</form>
$result = null;

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $recipient = new Recipient([
        'test' => $_POST['to'],
    ]);

    $result = $messaging->send(
        'test',
        $recipient,
        new Message($_POST['subject'], $_POST['message']),
    );
}

5. Show the delivery result

<?php if ($result): ?>
    <h2>Delivery</h2>
    <p><strong>Channel:</strong> test</p>
    <p><strong>Status:</strong> <?= $result->success ? 'Sent' : 'Failed' ?></p>
<?php endif; ?>

Keep the page focused on information a user or developer actually needs rather than dumping the complete internal object.

6. Developer tip: inspect the last Prefab operation

When operation tracing is available for the module, add one line after the operation:

$result = $messaging->send('test', $recipient, $message);

prefab_trace();

For the detailed internal steps:

prefab_trace(true);

Remove the trace line when it is no longer needed. The actual Messaging call remains unchanged.

7. Send email

Messaging has a short convenience API for mail:

$result = $messaging->mail(
    'user@example.com',
    'Annual Report',
    'Your report is ready.',
);

A mail channel must be configured before this can deliver anything.

8. Configure SMTP

use Tihloh\Prefab\Messaging\Channels\MailChannel;
use Tihloh\Prefab\Messaging\Mail\SmtpTransport;

$smtp = new SmtpTransport([
    'host' => 'smtp.example.com',
    'port' => 587,
    'username' => 'user@example.com',
    'password' => 'secret',
    'encryption' => 'tls',
    'from' => [
        'address' => 'noreply@example.com',
        'name' => 'My System',
    ],
]);

$messaging = new MessagingManager([
    new MailChannel($smtp),
]);

Your form and application-facing API do not need to change when the test channel is replaced by a real transport.

9. Templates

$template = new Template(
    subject: 'Hello {{name}}',
    text: 'Your report {{report}} is ready.'
);

$message = $template->render([
    'name' => 'Demo User',
    'report' => 'AR-2026',

10. Attachments

$message = new Message(
    subject: 'Report',
    text: 'Your report is attached.',
    attachments: [
        Attachment::fromPath('/tmp/report.pdf'),
    ],
);

11. React to delivery

$messaging->on('sent', function ($channel, $recipient, $message, $result) {
    // Message was delivered.
});

$messaging->on('failed', function ($channel, $recipient, $message, $result) {
    // Delivery failed.
});

Hooks are useful for audit logging, metrics or application-specific follow-up without changing the delivery channel.

12. What you built

You now have a simple message form that can use a local test channel or a real external transport while application code continues to use the same Messaging API.
