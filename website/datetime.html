Date & Time

Prefab Core wraps DateTimeImmutable with a small fluent API for common parsing, formatting, comparison and date arithmetic.

1. Create a date value

$date = prefab_datetime('2026-09-03 08:30:00');

prefab_datetime() is the collision-safe global helper. You can also use Tihloh\Prefab\Core\DateTime\Date::make() directly.

2. Format it

echo $date->date();
echo $date->time();
echo $date->datetime();
echo $date->iso();

3. Add and subtract time

$nextWeek = prefab_datetime()->addDays(7);
$yesterday = prefab_datetime()->subDays(1);

4. Compare values

$a = prefab_datetime('2026-09-01');
$b = prefab_datetime('2026-09-10');

$a->isBefore($b);
$b->isAfter($a);
$a->diffInDays($b);

5. Use with val()

$date = val('2026-09-03')->toDateTime();
echo $date->format('date');
