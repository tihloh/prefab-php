Production checklist

The tutorial uses PHP's built-in server for learning. Production deployment should use a real web server and production-safe configuration.

Composer

composer install --no-dev --optimize-autoloader

Application checklist

  • Use HTTPS.
  • Keep database credentials, API keys and mail credentials outside public source files.
  • Disable public PHP error display; log exceptions server-side.
  • Enable OPcache where appropriate.
  • Use secure session cookie settings and keep Prefab application isolation enabled.
  • Protect state-changing forms/endpoints with CSRF protection.
  • Add rate limiting around login/reset endpoints where appropriate.
  • Back up database and uploaded-file storage.
  • Use stable package releases.

Server-specific notes

Your Windows/Linux choice is remembered from the earlier tutorial pages. You can change it here at any time.

Windows

Windows server

Prefab is not Linux-only. PHP applications can run under IIS, Apache on Windows, or another compatible Windows deployment. Configure the site's document root to the application's public directory, use the production PHP configuration, and verify that the required PHP extensions are enabled.

Linux

Linux server

Apache or Nginx with PHP-FPM are common choices. Configure the document root to the application's public directory, keep private source and configuration outside direct web access, and enable the PHP extensions required by the application.
