Package availability and minimum-stability

Prefab source code can exist before a stable Packagist release exists. If Composer says:

Could not find a version of package tihloh/prefab-routes
matching your minimum-stability (stable).

Composer itself may be working correctly; it simply cannot resolve a stable published version.

Stable release

composer require tihloh/prefab-routes

Development/testing before stable release

composer require tihloh/prefab-routes:dev-main
Use :dev-main only when deliberately testing unreleased code. Prefer normal stable package requirements for production applications.
