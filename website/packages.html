Installing Prefab packages

Prefab is modular. Install only the feature modules your application needs. Composer automatically installs Prefab Core, which now provides the shared runtime, database, session and cache infrastructure.

Latest architecture: prefab-database is retired. Database functionality now lives in prefab-core. Feature packages depend on Core instead of carrying duplicated shared infrastructure.

1. Install a feature

Feature packages keep the familiar naming pattern:

composer require tihloh/prefab-<module>

For example:

composer require tihloh/prefab-routes

Composer installs the compatible Core dependency automatically.

2. Available feature packages

composer require tihloh/prefab-routes
composer require tihloh/prefab-users
composer require tihloh/prefab-auth
composer require tihloh/prefab-permissions
composer require tihloh/prefab-input
composer require tihloh/prefab-logs
composer require tihloh/prefab-files
composer require tihloh/prefab-notifications
composer require tihloh/prefab-messaging

3. Install Core directly only when needed

If your project specifically needs Core infrastructure without another feature package, install it directly:

composer require tihloh/prefab-core

Core contains the Prefab runtime/configuration system plus database, session, cache and diagnostics infrastructure.

4. What not to install

composer require tihloh/prefab-database

The standalone Database package has been retired. New code should use Tihloh\Prefab\Core\Database\DatabaseManager.

5. What Composer does

Composer records your selected feature in composer.json, resolves Core and other dependencies, downloads them into vendor/, updates composer.lock, and regenerates vendor/autoload.php.

For students: install the feature package shown by the tutorial. You normally do not need to think about Core until a lesson directly uses database, session, cache or runtime infrastructure.

6. Verify installed packages

composer show tihloh/prefab-routes
composer show tihloh/prefab-core

To see every installed Prefab package:

composer show "tihloh/prefab-*"
Do not continue after a failed Composer command. Fix the installation first, then continue with the tutorial code.
