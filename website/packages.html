Getting Started

Installing Prefab packages

Prefab is modular. You install only the modules your application needs, and Composer takes care of downloading them and generating the autoloader.

The normal installation command

Every Prefab module follows the same Composer naming pattern:

composer require tihloh/prefab-<module>

For example, to install Routes:

composer require tihloh/prefab-routes

You do not need to specify :dev-main, change minimum-stability, clone a module manually, or copy PHP files into your project.

What Composer does

When you run composer require, Composer records the package in composer.json, resolves a compatible release, downloads the package and its dependencies into vendor/, updates composer.lock, and regenerates vendor/autoload.php.

For students: use the exact normal commands shown throughout this tutorial. Development branches are a maintainer concern and are not part of the application installation procedure.

Verify an installed module

composer show tihloh/prefab-routes

If it is installed, Composer displays the package information and installed version. You can also list all installed Prefab packages:

composer show "tihloh/prefab-*"
Do not continue after a failed Composer command. A tutorial step that says composer require expects that command to complete successfully before you write code using that module.
