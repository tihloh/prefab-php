Routing

Connect HTTP requests to PHP handlers, then build up parameters, methods, groups, middleware and named URLs.

1. Install

composer require tihloh/prefab-routes

2. Create routes

<?php
require __DIR__ . '/../vendor/autoload.php';
use Tihloh\Prefab\Routes\RouteManager;
$routes = new RouteManager();
$routes->get('/', fn () => '<h1>Prefab Routes</h1>');
$routes->get('/hello/{name}', fn (string $name) => "Hello {$name}");
$result = $routes->dispatch();
if (is_string($result)) echo $result;

3. HTTP methods and parameters

$routes->get('/users/{id}', fn ($id) => "User {$id}");
$routes->post('/users', fn () => 'Create user');
$routes->put('/users/{id}', fn ($id) => "Update {$id}");
$routes->delete('/users/{id}', fn ($id) => "Delete {$id}");
$routes->get('/numbers/{id}', fn ($id) => $id)->where('id', '\d+');

4. Named routes

$routes->get('/profiles/{id}', fn ($id) => "Profile {$id}")->name('profiles.show');
echo $routes->url('profiles.show', ['id' => 25]);

5. Groups and middleware

$routes->middleware('demo-auth', function (callable $next, $match) {
    if (($_GET['key'] ?? '') !== 'secret') return 'Unauthorized';
    return $next();
});
$routes->group('/admin', function (RouteManager $routes) {
    $routes->get('/users', fn () => 'Admin users')->middleware('demo-auth');
});

6. Metadata and integration hints

$routes->get('/documents/{id}', fn ($id) => "Document {$id}")
->name('documents.show')
->auth()
->permission('documents.view')
->log('documents.view');

These helpers attach metadata. Middleware/integration code performs the actual authentication, authorization and logging.

7. Developer tip: trace routing

Call the trace helper after a traceable routing operation:

$match = $routes->match('GET', '/users/25');

prefab_trace();

Detailed mode:

prefab_trace(true);

Tracing is optional developer output and should not replace the route's normal response.

8. Route diagnostics

print_r($routes->table());
print_r($routes->explain());
