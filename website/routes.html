Routing

A route maps an HTTP method and URL path to PHP code. Start here so later pages can build actual application endpoints.

Install

composer require tihloh/prefab-routes

First routes

<?php
require __DIR__ . '/../vendor/autoload.php';

use Tihloh\Prefab\Routes\RouteManager;

$routes = new RouteManager();
$routes->get('/', fn () => 'Home');
$routes->get('/hello', fn () => 'Hello Prefab!');

$result = $routes->dispatch();
if (is_string($result)) {
    echo $result;
}

Try it

With php -S 127.0.0.1:8000 -t public running, open / and /hello. Routes works independently; Users, Auth and Permissions are not required.

Checkpoint: both URLs respond through the router.
