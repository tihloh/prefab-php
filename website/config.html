Shared Prefab configuration

Use shared configuration for resources and values that genuinely belong to the whole application.

use Tihloh\Prefab\PrefabConfig;

PrefabConfig::set([
    'name' => 'my_app',
    'database' => $pdo,
]);

Resolution principle

Module-local configuration
        ↓
Module PrefabConfig override
        ↓
Shared PrefabConfig
        ↓
Compatible discovered capability
        ↓
Internal default

Explicit module configuration should win over automatic behavior. Shared config prevents repeated settings, but does not remove the ability to override one module.

Keep display names and machine identifiers conceptually separate. A long application display name does not need to become a session namespace or filesystem identifier.
