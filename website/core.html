Prefab Core

Core is the small shared foundation used by Prefab modules. It provides common infrastructure without turning Prefab into a full framework.

1. How Core is installed

When you install a feature package such as Routes, Users or Logs, Composer installs tihloh/prefab-core automatically when that package requires it. You may also install Core directly.

composer require tihloh/prefab-core

2. What Core provides

Core
├─ Values: val()
├─ Environment: .env and prefab_env()
├─ Date & time
├─ Database basics
├─ Session
├─ Cache
├─ CLI
├─ Runtime / configuration
└─ Diagnostics / trace

Business features remain separate packages. Core does not own users, authentication rules, permissions, audit logs, routing, files, messaging or notifications.

3. The intended experience

Core is designed to make ordinary PHP shorter while keeping native PHP underneath.

$age = val($_POST['age'] ?? null)
    ->toInt()
    ->fallback(0);

$host = prefab_env('DB_HOST', '127.0.0.1');

prefab_trace();
