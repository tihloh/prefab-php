Input and validation

Build a working form with plain HTML. Invalid input shows useful messages and valid input produces data ready for the rest of the application.

1. Install

composer require tihloh/prefab-input

2. Process the form

<?php
require __DIR__ . '/../vendor/autoload.php';
use Tihloh\Prefab\Input\Input;
$errors = [];
$valid = null;
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $result = Input::from($_POST)->process([
        'name' => 'trim|required|string|max:100',
        'email' => 'trim|lowercase|required|email',
        'age' => 'required|integer|min:18',
    ]);
    $errors = $result->errors();
    $valid = $result->fails() ? null : $result->validated();
}

3. Add the form

<form method="post">
<p><input name="name" placeholder="Name"></p>
<p><input name="email" placeholder="Email"></p>
<p><input name="age" placeholder="Age"></p>
<button>Register</button>
</form>

4. Show errors and success

<?php if ($errors): ?>
<ul><?php foreach ($errors as $field => $messages): ?>
<li><?= htmlspecialchars($field) ?>: <?= htmlspecialchars($messages[0]) ?></li>
<?php endforeach; ?></ul>
<?php endif; ?>
<?php if ($valid): ?>
<p><b>Registration successful!</b> Welcome, <?= htmlspecialchars($valid['name']) ?>.</p>
<?php endif; ?>
Checkpoint: Invalid values show validation messages; valid values show the success result.

5. Use validated data

if ($valid) {
    $users->create($valid);
}

6. Developer tip: trace validation

After processing the input, inspect the latest Prefab operation when debugging:

$result = Input::from($_POST)->process($schema);

prefab_trace();

Detailed mode:

prefab_trace(true);

Keep validation messages and normal application results visible; tracing is optional developer output.

7. Uploads

Input::fromRequest() can collect request values and uploaded files together. Validate uploads before handing them to Files.
