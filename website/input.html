Input and validation

Validate browser input before passing it to Users, database code, or business logic.

Install

composer require tihloh/prefab-input

Validate a registration form

use Tihloh\Prefab\Input\Input;

$result = Input::from($_POST)->process([
    'name' => 'trim|required|string|max:100',
    'email' => 'trim|lowercase|required|email',
    'password' => 'required|string|min:8',
]);

if ($result->fails()) {
    print_r($result->errors());
    return;
}

$users->create($result->validated());

Why use validated data?

validated() returns only fields accepted by your rules. The application still decides whether errors become HTML, JSON, redirects, or API responses.

Checkpoint: submit an invalid email, then a valid one. Only the valid request should reach user creation.
