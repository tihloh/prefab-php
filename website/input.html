Input and validation

Build a real browser form, submit invalid and valid data, and see exactly what Prefab Input accepts.

Install

composer require tihloh/prefab-input

Create public/input.php

This example is intentionally standalone. It does not require Database, Users, Routes, Auth, or another Prefab module.

<?php
require __DIR__ . '/../vendor/autoload.php';

use Tihloh\Prefab\Input\Input;

$errors = [];
$valid = null;

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $result = Input::from($_POST)->process([
        'name' => 'trim|required|string|max:100',
        'email' => 'trim|lowercase|required|email',
        'age' => 'required|integer|min:18',
    ]);

    if ($result->fails()) {
        $errors = $result->errors();
    } else {
        $valid = $result->validated();
    }
}
?>
<!doctype html>
<html>
<body>
    <h1>Prefab Input Test</h1>

    <form method="post">
        <p>
            <label>Name<br>
                <input name="name" value="<?= htmlspecialchars($_POST['name'] ?? '') ?>">
            </label>
        </p>
        <p>
            <label>Email<br>
                <input name="email" value="<?= htmlspecialchars($_POST['email'] ?? '') ?>">
            </label>
        </p>
        <p>
            <label>Age<br>
                <input name="age" value="<?= htmlspecialchars($_POST['age'] ?? '') ?>">
            </label>
        </p>
        <button type="submit">Validate</button>
    </form>

    <?php if ($errors): ?>
        <h2>Validation errors</h2>
        <pre><?= htmlspecialchars(print_r($errors, true)) ?></pre>
    <?php endif; ?>

    <?php if ($valid !== null): ?>
        <h2>Validated data</h2>
        <pre><?= htmlspecialchars(print_r($valid, true)) ?></pre>
    <?php endif; ?>
</body>
</html>

Run it

If your local server is not already running:

php -S 127.0.0.1:8000 -t public

Open http://127.0.0.1:8000/input.php.

Test invalid input

Try:

Name:   Demo User
Email:  not-an-email
Age:    15

You should see validation errors for email and age.

Test valid input

Now try:

Name:   Demo User
Email:  DEMO@EXAMPLE.COM
Age:    25

The validated result should contain a lowercased email and integer age. This demonstrates validation, transformation, type casting, and the validated-field whitelist in one browser test.

Why use validated()?

validated() contains only fields declared by your schema that passed processing. After this boundary, you can safely pass the accepted data to your own database code, Users module, service layer, or business logic.

Checkpoint: invalid data displays errors; valid data displays a clean array containing only name, email, and age.
