Authentication

Authentication answers one question: who is signed in?

Install

composer require tihloh/prefab-auth

Login

use Tihloh\Prefab\Auth\Services\AuthManager;

$auth = new AuthManager();
$result = $auth->attempt($email, $password);

if (!$result->success) {
    echo 'Invalid login';
}

If Prefab Users is installed and compatible, Auth can discover its user provider. Normal application code does not need to call internal configuration methods just to connect them.

Current user

$auth->check();
$auth->id();
$auth->user();
$auth->logout();

Session safety

Prefab's native session handling isolates applications by default so apps such as localhost/web1 and localhost/web2 do not accidentally share authentication state. The dedicated Session Isolation reference explains the rules.

Checkpoint: test a failed login, a successful login, current-user lookup and logout.
