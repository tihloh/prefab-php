Authentication

Use the real user created in the Users tutorial, then test failed login, successful login, session persistence, current-user lookup and logout through an actual browser screen.

Install

composer require tihloh/prefab-auth

Prerequisite

Complete the Users tutorial first and create a user with a known email/password. The users table must contain id, email, password_hash and active.

Create public/auth.php

<?php
require __DIR__ . '/../vendor/autoload.php';

use Tihloh\Prefab\Auth\Contracts\AuthenticatableUserInterface;
use Tihloh\Prefab\Auth\Contracts\AuthUserProviderInterface;
use Tihloh\Prefab\Auth\Services\AuthManager;
use Tihloh\Prefab\Auth\Session\NativeSessionStore;

final class TutorialAuthUser implements AuthenticatableUserInterface
{
    public function __construct(
        public int $id,
        public string $email,
        private ?string $passwordHash,
        public bool $active,
    ) {}

    public function authId(): int|string { return $this->id; }
    public function authPasswordHash(): ?string { return $this->passwordHash; }
    public function authIsActive(): bool { return $this->active; }
}

final class TutorialAuthProvider implements AuthUserProviderInterface
{
    public function __construct(private PDO $pdo) {}

    public function findByIdentifier(string $identifier): ?AuthenticatableUserInterface
    {
        $stmt = $this->pdo->prepare('SELECT id,email,password_hash,active FROM users WHERE email = ? LIMIT 1');
        $stmt->execute([$identifier]);
        $row = $stmt->fetch(PDO::FETCH_ASSOC);
        return $row ? $this->make($row) : null;
    }

    public function findById(int|string $id): ?AuthenticatableUserInterface
    {
        $stmt = $this->pdo->prepare('SELECT id,email,password_hash,active FROM users WHERE id = ? LIMIT 1');
        $stmt->execute([$id]);
        $row = $stmt->fetch(PDO::FETCH_ASSOC);
        return $row ? $this->make($row) : null;
    }

    private function make(array $row): TutorialAuthUser
    {
        return new TutorialAuthUser(
            (int) $row['id'],
            $row['email'],
            $row['password_hash'],
            (bool) $row['active'],
        );
    }
}

$pdo = new PDO(
    'mysql:host=127.0.0.1;dbname=prefab_tutorial;charset=utf8mb4',
    'root',
    '',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

$auth = new AuthManager(
    new TutorialAuthProvider($pdo),
    new NativeSessionStore(),
);

$message = '';

if (isset($_POST['logout'])) {
    $auth->logout();
    $message = 'Logged out.';
}

if (isset($_POST['login'])) {
    $result = $auth->attempt(
        $_POST['email'] ?? '',
        $_POST['password'] ?? '',
        [
            'ip_address' => $_SERVER['REMOTE_ADDR'] ?? null,
            'user_agent' => $_SERVER['HTTP_USER_AGENT'] ?? null,
        ],
    );
    $message = $result->success ? 'Login successful.' : 'Invalid login.';
}
?>
<!doctype html>
<html><body>
<h1>Prefab Auth Test</h1>
<p><?= htmlspecialchars($message) ?></p>

<?php if ($auth->check()): ?>
    <h2>Logged in</h2>
    <p>User ID: <?= htmlspecialchars((string) $auth->id()) ?></p>
    <p>Email: <?= htmlspecialchars($auth->user()->email) ?></p>
    <form method="post">
        <button name="logout" value="1">Logout</button>
    </form>
<?php else: ?>
    <h2>Login</h2>
    <form method="post">
        <p><input name="email" type="email" placeholder="Email" required></p>
        <p><input name="password" type="password" placeholder="Password" required></p>
        <button name="login" value="1">Login</button>
    </form>
<?php endif; ?>
</body></html>

Run and test

php -S 127.0.0.1:8000 -t public

Open http://127.0.0.1:8000/auth.php.

Test 1 — wrong password

Use the correct email but an incorrect password. You should see Invalid login.

Test 2 — correct login

Use the password you entered in the Users tutorial. The screen should show the authenticated user ID and email.

Test 3 — session persistence

Refresh the page. $auth->check(), $auth->id() and $auth->user() should still identify the user.

Test 4 — inactive user

Deactivate the same account in users.php, log out, then attempt to sign in again.

Test 5 — logout

Click Logout and confirm the login form returns.

Core API

$auth->check();
$auth->id();
$auth->user();
$auth->logout();

Authentication result and logging

$result = $auth->attempt($email, $password);
if ($result->success) {
    $logs?->record($result->log);
}

Social authentication

Social login requires a real OAuth provider configuration, callback URL and a SocialUserResolverInterface. The package supports provider registration, authorization URLs, callback handling, account lookup and unlinking; those examples should only be tested after provider credentials exist.

$url = $social->authorizationUrl('google');
header('Location: ' . $url);

$result = $social->callback('google', $_GET);
$accounts = $social->accountsForUser($userId);
$social->unlink($userId, 'google');
Why this tutorial uses an explicit provider: Auth intentionally does not own the users table. The tutorial therefore shows the complete contract boundary instead of pretending that a user database appears automatically.
Checkpoint: you can visibly test failed login, successful login, current session/user, inactive-account rejection and logout from a browser.
