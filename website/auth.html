Authentication

Start with password login using Prefab Users and Auth. Add PIN, tokens and other methods only when the application needs them.

1. Install

composer require tihloh/prefab-auth

2. Create Users and Auth

use Tihloh\Prefab\Users\Services\UserManager;
use Tihloh\Prefab\Auth\Services\AuthManager;
$users = new UserManager(['database' => $pdo]);
$auth = new AuthManager(['database' => $pdo]);

Users owns identity/profile data. Auth owns credentials and sessions.

3. Set a password

$alice = $users->findByEmail('alice@example.com');
if ($alice && !$auth->hasPassword($alice->id)) {
    $auth->setPassword($alice->id, 'secret123');
}

4. Login

$result = $auth->attempt(
    $_POST['identifier'] ?? '',
    $_POST['password'] ?? '',
);
$message = $result->success ? 'Login successful.' : 'Invalid login.';
<form method="post">
<input name="identifier" placeholder="Email" required>
<input name="password" type="password" placeholder="Password" required>
<button>Login</button>
</form>
<p><?= htmlspecialchars($message) ?></p>
Checkpoint: A valid account displays “Login successful.”

5. Current user and logout

if ($auth->check()) {
    echo 'User #' . htmlspecialchars((string) $auth->id());
}
// $auth->user();
// $auth->logout();

6. Optional login methods

$auth->setPin($alice->id, '1234');
$auth->attemptPin('alice@example.com', '1234');
$token = $auth->createLoginToken($alice->id);
$auth->attemptToken($token);

7. Developer tip: trace authentication

Trace after the normal Auth call. Passwords/tokens should never be deliberately printed as diagnostic output.

$result = $auth->attempt($identifier, $password);

prefab_trace();

Detailed mode:

prefab_trace(true);

Keep the normal login success/error message as the user-facing result.

8. Configuration diagnostics

print_r($auth->explain());
