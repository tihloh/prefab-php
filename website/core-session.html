Session

Core provides session storage mechanics. Authentication rules remain in Prefab Auth.

1. Create a session store

use Tihloh\Prefab\Core\Session\NativeSession;

$session = new NativeSession();

2. Read and write values

$session->set('user_id', 42);
$id = $session->get('user_id');

$session->has('user_id');
$session->remove('user_id');

3. Flash data

$session->flash('success', 'Saved!');

Flash values are intended for short-lived messages such as success or error notices between requests.

4. Session lifecycle

$session->regenerate();
$session->destroy();

Use regeneration around identity/session transitions. Core only provides the mechanism; Auth decides when login/logout behavior should happen.
