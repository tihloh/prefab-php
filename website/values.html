Values with val()

val() wraps an ordinary PHP value so it can be inspected, transformed, converted, formatted and recovered fluently.

1. Basic transformations

$name = val(' Christian ')->trim()->upper();
$age = val('35')->toInt();
$enabled = val('true')->toBool();

The wrapper stays fluent so more operations can follow. Use ->value() only when an external PHP API specifically needs the raw native value.

2. Defaults and fallbacks

$name = val($name)->default('Guest');
$age = val($input)->toInt()->fallback(0);

default() replaces null, an empty string or an empty array. It preserves meaningful falsey values such as 0 and false. fallback() also recovers from failed conversions.

3. Nested data

$name = val($data)
    ->get('user.profile.name')
    ->default('Guest');

4. Formatting

echo val(12500)->format('currency', ['currency' => 'PHP']);
echo val('09171234567')->format('phone');
echo val(0.75)->format('percent');

5. Database boundaries

Prefab Core's query builder understands Value objects and unwraps them before PDO receives them.

$db->table('users')->insert([
    'name' => val($_POST['name'] ?? null)->trim()->default('Unknown'),
    'age' => val($_POST['age'] ?? null)->toInt()->fallback(0),
]);
Checkpoint: You can keep values fluent through application code without manually unwrapping them before Prefab database operations.
