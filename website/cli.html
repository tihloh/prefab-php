Command Line

Prefab Core includes a lightweight console for project and feature commands without introducing a full framework CLI.

1. Built-in commands

Windows

PowerShell

.\vendor\bin\prefab list
.\vendor\bin\prefab help init
.\vendor\bin\prefab about
.\vendor\bin\prefab init
Linux / macOS

Shell

./vendor/bin/prefab list
./vendor/bin/prefab help init
./vendor/bin/prefab about
./vendor/bin/prefab init

2. Initialize optional project folders

config/
bootstrap/
storage/
app/Console/

prefab init creates these folders only when requested. Prefab does not require a fixed application structure.

3. Register a command

use Tihloh\Prefab\Core\Console\Input;
use Tihloh\Prefab\Core\Console\Output;

prefab_command('user:create', function (Input $input, Output $output) {
    $name = $input->argument(0);
    $email = $input->option('email');
    $admin = $input->flag('admin');

    $output->info("Creating {$name}");
}, 'Create a user');

4. Run it

./vendor/bin/prefab user:create Juan --admin --email=juan@example.com

If bootstrap/prefab.php exists in the current project, the CLI loads it before dispatching commands.
