Tutorial · Module 3

Users

Start by reading one user. Then add listing, a create form, editing and deletion. Only after the basics work will we explore custom mappings and diagnostics.

Learning style: complete one slice, test it, then continue. Do not copy the whole tutorial at once.

1. Install

composer require tihloh/prefab-users

2. Create the smallest useful table

Use the prefab_tutorial database from the Database tutorial.

CREATE TABLE users (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(190) NOT NULL UNIQUE,
    active TINYINT(1) NOT NULL DEFAULT 1
);

Add one user so we have something to read:

INSERT INTO users (name, email)
VALUES ('Alice', 'alice@example.com');
Checkpoint: your users table contains Alice.

3. Connect Prefab Users

Create public/users.php. For now it only loads one user.

<?php
require __DIR__ . '/../vendor/autoload.php';

use Tihloh\Prefab\Users\Mapping\UserMap;
use Tihloh\Prefab\Users\Repositories\PdoUserProvider;
use Tihloh\Prefab\Users\Services\UserManager;

$pdo = new PDO(
    'mysql:host=127.0.0.1;dbname=prefab_tutorial;charset=utf8mb4',
    'root',
    '',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

$map = new UserMap(table: 'users');
$users = new UserManager(new PdoUserProvider($pdo, $map));

$user = $users->find(1);
?>
<h1>User</h1>
<p><?= htmlspecialchars($user?->name ?? 'Not found') ?></p>

Run the project:

php -S 127.0.0.1:8000 -t public

Open http://127.0.0.1:8000/users.php.

Checkpoint: the browser displays Alice. Stop here until it works.

4. List users

Replace the single $user = ... line with:

$list = $users->all();

Then replace the current heading/paragraph at the bottom with:

<h1>Users</h1>
<?php foreach ($list as $user): ?>
    <p>
        #<?= $user->id ?>
        <?= htmlspecialchars($user->name ?? '') ?>
        — <?= htmlspecialchars($user->email ?? '') ?>
    </p>
<?php endforeach; ?>
Checkpoint: Alice appears in the list.

5. Add a create form

Now make the page interactive. Add this before $list = $users->all();:

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $users->create([
        'name' => trim($_POST['name'] ?? ''),
        'email' => trim($_POST['email'] ?? ''),
        'active' => true,
    ]);
}

Add this form above the user list:

<h2>Create user</h2>
<form method="post">
    <input name="name" placeholder="Name" required>
    <input name="email" type="email" placeholder="Email" required>
    <button>Create</button>
</form>

Create Bob from the browser.

Checkpoint: Bob appears below Alice without manually inserting SQL.

6. Find by ID or email

Once create/list works, try the lookup methods separately:

$user = $users->find(1);
$byEmail = $users->findByEmail('alice@example.com');

print_r($byEmail?->toArray());

7. Update a user

Add a small update test before loading the list:

if (isset($_POST['rename'])) {
    $users->update((int) $_POST['id'], [
        'name' => trim($_POST['name']),
    ]);
}

Inside the existing foreach, add:

<form method="post">
    <input type="hidden" name="id" value="<?= $user->id ?>">
    <input name="name" value="<?= htmlspecialchars($user->name ?? '') ?>">
    <button name="rename" value="1">Rename</button>
</form>
Checkpoint: rename Bob and refresh. The new name remains.

8. Active/inactive users

The table already has an active column. Update it like any mapped core field:

$users->update($userId, ['active' => false]);

Inspect it with:

$user = $users->find($userId);
var_dump($user?->active);

9. Delete — enable it intentionally

Deletion is disabled by default. Change your map only when you are ready to test destructive operations:

$map = new UserMap(
    table: 'users',
    allowDelete: true,
);

Then test:

$users->delete($userId);
Checkpoint: create a temporary user, delete it, and confirm it disappears.

10. Build on it — custom project fields

Now that basic CRUD is clear, add project-specific columns:

ALTER TABLE users
ADD office VARCHAR(100) NULL,
ADD password_hash VARCHAR(255) NULL;

Expand the map:

$map = new UserMap(
    table: 'users',
    attributes: [
        'office' => 'office',
        'password_hash' => 'password_hash',
    ],
    allowDelete: true,
);

Prefab exposes those attributes on the user object:

echo $user->office;
echo $user->get('office');
print_r($user->attributes());

11. Advanced — map an existing schema

Your application does not need to rename its existing columns to use Prefab.

$map = new UserMap(
    table: 'employees',
    id: 'employee_id',
    name: 'full_name',
    email: 'email_address',
    active: 'is_active',
    attributes: [
        'office' => 'office_name',
        'position' => 'position_title',
        'employee_no' => 'employee_no',
    ],
);

12. Advanced — restrict writes

$map = new UserMap(
    table: 'employees',
    id: 'employee_id',
    name: 'full_name',
    email: 'email_address',
    active: 'is_active',
    allowCreate: false,
    allowUpdate: false,
    allowDelete: false,
);
