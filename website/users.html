Users

Build a simple user-management page with plain HTML, then inspect what Prefab does behind the curtain with its developer trace.

1. Install

composer require tihloh/prefab-users

2. Connect Users

<?php
require __DIR__ . '/../vendor/autoload.php';
use Tihloh\Prefab\Users\Services\UserManager;
$pdo = new PDO('mysql:host=127.0.0.1;dbname=prefab_tutorial;charset=utf8mb4','root','',[PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]);
$users = new UserManager(['database' => $pdo]);

3. Add a user

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $users->create(['name' => trim($_POST['name'] ?? ''),'email' => trim($_POST['email'] ?? ''),'active' => true]);
}
$list = $users->all();
<form method="post"><input name="name" placeholder="Name" required><input name="email" type="email" placeholder="Email" required><button>Add user</button></form>

4. Display users

<table border="1" cellpadding="8"><tr><th>ID</th><th>Name</th><th>Email</th></tr>
<?php foreach ($list as $user): ?><tr><td><?= $user->id ?></td><td><?= htmlspecialchars($user->name ?? '') ?></td><td><?= htmlspecialchars($user->email ?? '') ?></td></tr><?php endforeach; ?></table>

5. Trace what happened

prefab_trace() shows a clean high-level execution tree in a theme-independent Prefab Debug card.

$list = $users->all();
prefab_trace();

For deeper debugging use the explicit detailed helper:

$list = $users->all();
prefab_trace_detailed();

Detailed mode includes internal steps, timings and database SQL when available. Sensitive credentials remain hidden.

Development only: diagnostics print into the response. Remove them from production pages.

6. Explain one module

$users->explain() focuses the diagnostic execution story on Users. Structured configuration data is separately available through $users->explainData().

$users->explain();
