Users and simple Groups

Prefab Users manages user records and simple group organization. Permissions remain optional.

Install

composer require tihloh/prefab-users

Create the manager

use Tihloh\Prefab\Users\Services\UserManager;

$users = new UserManager([
    'database' => $pdo,
    'table' => 'users',
]);

Common user operations

$user = $users->find(1);
$all  = $users->all();

$result = $users->create([
    'name' => 'Demo User',
    'email' => 'demo@example.com',
    'password' => password_hash('secret123', PASSWORD_DEFAULT),
]);

Simple groups

$groups = $users->groups();
$staff = $groups->create('Staff', 'Application staff');
$groups->addUser($userId, $staff->id);
$groups->syncUserGroups($userId, [1, 2]);

A simple group contains an ID, name, optional description and membership. When Permissions is installed later, it can add authorization to these same logical groups.

Checkpoint: create a user and one group, then attach the user to the group.
