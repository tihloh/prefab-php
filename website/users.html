Tutorial · Module 3

Users

In this tutorial, you will start by reading a single user, then gradually add listing, creation, editing and deletion. The final sections cover custom mappings and diagnostics.

1. Install

composer require tihloh/prefab-users

2. Create the users table

Use the prefab_tutorial database created in the Database tutorial.

CREATE TABLE users (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(190) NOT NULL UNIQUE,
    active TINYINT(1) NOT NULL DEFAULT 1
);

Add a sample user:

INSERT INTO users (name, email)
VALUES ('Alice', 'alice@example.com');
Checkpoint: The users table should now contain Alice.

3. Load a user with Prefab Users

Create public/users.php:

<?php
require __DIR__ . '/../vendor/autoload.php';

use Tihloh\Prefab\Users\Mapping\UserMap;
use Tihloh\Prefab\Users\Repositories\PdoUserProvider;
use Tihloh\Prefab\Users\Services\UserManager;

$pdo = new PDO(
    'mysql:host=127.0.0.1;dbname=prefab_tutorial;charset=utf8mb4',
    'root',
    '',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

$map = new UserMap(table: 'users');
$users = new UserManager(new PdoUserProvider($pdo, $map));

$user = $users->find(1);
?>
<h1>User</h1>
<p><?= htmlspecialchars($user?->name ?? 'Not found') ?></p>

Start the PHP development server:

php -S 127.0.0.1:8000 -t public

Open http://127.0.0.1:8000/users.php.

Checkpoint: The page should display Alice.

4. List all users

Replace the single $user = ... line with:

$list = $users->all();

Replace the heading and paragraph at the bottom with:

<h1>Users</h1>
<?php foreach ($list as $user): ?>
    <p>#<?= $user->id ?> <?= htmlspecialchars($user->name ?? '') ?> — <?= htmlspecialchars($user->email ?? '') ?></p>
<?php endforeach; ?>
Checkpoint: Alice should appear in the list.

5. Create users from a form

Add this before $list = $users->all();:

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $users->create([
        'name' => trim($_POST['name'] ?? ''),
        'email' => trim($_POST['email'] ?? ''),
        'active' => true,
    ]);
}

Add the form above the user list:

<h2>Create user</h2>
<form method="post">
    <input name="name" placeholder="Name" required>
    <input name="email" type="email" placeholder="Email" required>
    <button>Create</button>
</form>

Enter Bob as a second user and submit the form.

Checkpoint: Bob should appear below Alice.

6. Find a user

Users can be retrieved by ID or email address:

$user = $users->find(1);
$byEmail = $users->findByEmail('alice@example.com');
print_r($byEmail?->toArray());

7. Update a user

Add an update handler before loading the list:

if (isset($_POST['rename'])) {
    $users->update((int) $_POST['id'], [
        'name' => trim($_POST['name']),
    ]);
}

Inside the existing foreach, add:

<form method="post">
    <input type="hidden" name="id" value="<?= $user->id ?>">
    <input name="name" value="<?= htmlspecialchars($user->name ?? '') ?>">
    <button name="rename" value="1">Rename</button>
</form>
Checkpoint: Rename Bob and refresh the page. The new name should remain.

8. Active and inactive users

The active field can be updated like other mapped fields:

$users->update($userId, ['active' => false]);

Read the updated value:

$user = $users->find($userId);
var_dump($user?->active);

9. Delete a user

Deletion is disabled by default. Enable it in the map when the application needs delete operations:

$map = new UserMap(
    table: 'users',
    allowDelete: true,
);

A user can then be deleted by ID:

$users->delete($userId);
Checkpoint: Create a temporary user, delete it, and confirm that it no longer appears in the list.

10. Custom project fields

User tables often contain application-specific profile fields. Add an office field:

ALTER TABLE users
ADD office VARCHAR(100) NULL;

Map the field as an attribute:

$map = new UserMap(
    table: 'users',
    attributes: [
        'office' => 'office',
    ],
    allowDelete: true,
);

The attribute is now available from the user object:

echo $user->office;
echo $user->get('office');
print_r($user->attributes());

Password credentials are handled by the Authentication module and do not need to be stored in the user profile table.

11. Advanced: map an existing schema

Prefab Users can map an existing table even when its column names are different:

$map = new UserMap(
    table: 'employees',
    id: 'employee_id',
    name: 'full_name',
    email: 'email_address',
    active: 'is_active',
    attributes: [
        'office' => 'office_name',
        'position' => 'position_title',
        'employee_no' => 'employee_no',
    ],
);

12. Advanced: restrict writes

Existing data sources can be configured as read-only:

$map = new UserMap(
    table: 'employees',
    id: 'employee_id',
    name: 'full_name',
    email: 'email_address',
    active: 'is_active',
    allowCreate: false,
    allowUpdate: false,
    allowDelete: false,
);

13. Advanced: diagnostics

Use explain() to inspect the current Users configuration:

print_r($users->explain());
