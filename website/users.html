Users

Build a simple user-management page with plain HTML, then use Prefab tracing as an optional developer diagnostic.

1. Install

composer require tihloh/prefab-users

2. Connect Users

<?php
require __DIR__ . '/../vendor/autoload.php';
use Tihloh\Prefab\Users\Services\UserManager;
$pdo = new PDO('mysql:host=127.0.0.1;dbname=prefab_tutorial;charset=utf8mb4','root','',[PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]);
$users = new UserManager(['database' => $pdo]);
$list = $users->all();

3. Display users

<table border="1" cellpadding="8">
<tr><th>ID</th><th>Name</th><th>Email</th><th>Status</th></tr>
<?php foreach ($list as $user): ?>
<tr><td><?= $user->id ?></td><td><?= htmlspecialchars($user->name ?? '') ?></td><td><?= htmlspecialchars($user->email ?? '') ?></td><td><?= $user->active ? 'Active' : 'Inactive' ?></td></tr>
<?php endforeach; ?>
</table>

4. Add a user

$result = $users->create([
    'name' => trim($_POST['name'] ?? ''),
    'email' => trim($_POST['email'] ?? ''),
    'active' => true,
]);
<form method="post">
<input name="name" placeholder="Name" required>
<input name="email" type="email" placeholder="Email" required>
<button>Add user</button>
</form>
Checkpoint: Add a user and confirm the new row appears in the table.

5. Find, update and delete

$user = $users->find(1);
$byEmail = $users->findByEmail('alice@example.com');
$users->update(1, ['name' => 'Alice Smith']);
// $users->delete(1); // only when deletion is enabled by the map

6. Map an existing table

use Tihloh\Prefab\Users\Mapping\UserMap;
$map = new UserMap(table:'employees', id:'employee_id', name:'full_name', email:'email_address', active:'is_active');
$users = new UserManager(['database' => $pdo, 'map' => $map]);

7. Developer tip: trace the operation

Keep normal application output as the main result. When debugging, call the trace helper after the Prefab operation:

$result = $users->create($data);

prefab_trace();

For detailed internal steps:

prefab_trace(true);

Tracing is a developer diagnostic and should not replace the user-facing users table.

8. Configuration diagnostics

print_r($users->explain());

Users owns identity/profile data. Auth owns credentials, Permissions owns authorization, and Logs owns persistent activity history.
