Users

Create a real users table and browser page so you can test mapping, create, list, find, update, delete, custom attributes and diagnostics.

Install

composer require tihloh/prefab-users

Create the table

Use the same prefab_tutorial database from the Database tutorial:

CREATE TABLE users (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(190) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NULL,
    active TINYINT(1) NOT NULL DEFAULT 1,
    office VARCHAR(100) NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Create public/users.php

<?php
require __DIR__ . '/../vendor/autoload.php';

use Tihloh\Prefab\Users\Mapping\UserMap;
use Tihloh\Prefab\Users\Repositories\PdoUserProvider;
use Tihloh\Prefab\Users\Services\UserManager;

$pdo = new PDO(
    'mysql:host=127.0.0.1;dbname=prefab_tutorial;charset=utf8mb4',
    'root',
    '',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

$map = new UserMap(
    table: 'users',
    id: 'id',
    name: 'name',
    email: 'email',
    active: 'active',
    attributes: [
        'password_hash' => 'password_hash',
        'office' => 'office',
    ],
    allowCreate: true,
    allowUpdate: true,
    allowDelete: true,
);

$users = new UserManager(new PdoUserProvider($pdo, $map));
$message = '';

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $action = $_POST['action'] ?? 'create';

    if ($action === 'create') {
        $user = $users->create([
            'name' => trim($_POST['name'] ?? ''),
            'email' => trim($_POST['email'] ?? ''),
            'password_hash' => password_hash($_POST['password'] ?? '', PASSWORD_DEFAULT),
            'office' => trim($_POST['office'] ?? ''),
            'active' => isset($_POST['active']),
        ]);
        $message = "Created user #{$user->id}";
    }

    if ($action === 'update') {
        $id = (int) ($_POST['id'] ?? 0);
        $users->update($id, [
            'name' => trim($_POST['name'] ?? ''),
            'office' => trim($_POST['office'] ?? ''),
            'active' => isset($_POST['active']),
        ]);
        $message = "Updated user #{$id}";
    }

    if ($action === 'delete') {
        $id = (int) ($_POST['id'] ?? 0);
        $users->delete($id);
        $message = "Deleted user #{$id}";
    }
}

$list = $users->all();
?>
<!doctype html>
<html><body>
<h1>Prefab Users Test</h1>
<p><?= htmlspecialchars($message) ?></p>

<h2>Create user</h2>
<form method="post">
    <input type="hidden" name="action" value="create">
    <p><input name="name" placeholder="Name" required></p>
    <p><input name="email" type="email" placeholder="Email" required></p>
    <p><input name="password" type="password" placeholder="Password" required></p>
    <p><input name="office" placeholder="Office"></p>
    <p><label><input type="checkbox" name="active" checked> Active</label></p>
    <button>Create</button>
</form>

<h2>Users</h2>
<?php foreach ($list as $user): ?>
    <form method="post" style="border:1px solid #ccc;padding:10px;margin:10px 0">
        <input type="hidden" name="id" value="<?= $user->id ?>">
        <p>#<?= $user->id ?> — <?= htmlspecialchars($user->email ?? '') ?></p>
        <input name="name" value="<?= htmlspecialchars($user->name ?? '') ?>">
        <input name="office" value="<?= htmlspecialchars($user->office ?? '') ?>">
        <label><input type="checkbox" name="active" <?= $user->active ? 'checked' : '' ?>> Active</label>
        <button name="action" value="update">Update</button>
        <button name="action" value="delete" onclick="return confirm('Delete this user?')">Delete</button>
    </form>
<?php endforeach; ?>
</body></html>

Run and test

php -S 127.0.0.1:8000 -t public

Open http://127.0.0.1:8000/users.php. Create at least two users, edit one, deactivate one, then delete one.

Custom project columns

The tutorial maps office and password_hash as project-specific attributes. Access them through the resulting user object:

echo $user->office;
echo $user->get('office');
print_r($user->attributes());

Read-only or restricted mappings

$map = new UserMap(
    table: 'employees',
    id: 'employee_id',
    name: 'full_name',
    email: 'email_address',
    active: 'is_active',
    allowCreate: false,
    allowUpdate: false,
