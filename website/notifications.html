Notifications

Use Notifications for notices that belong inside the application.

Install

composer require tihloh/prefab-notifications

Keep business intent explicit

Installing Notifications should not mean every user update automatically creates a notification. Your application decides when a notification is meaningful.

// Example intent
$user = $users->update($id, $data);

$notifications->send(
    $userId,
    'Your profile was updated.'
);

Cooperation

When compatible fluent extensions are available, Prefab may offer shorter explicit operations, but the decision to notify still comes from your application.

Checkpoint: create one notification and confirm it is associated with the intended recipient.
