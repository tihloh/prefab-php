Auto-Wiring

Auto-wiring is Prefab's interoperability layer: modules publish capabilities and compatible modules consume what they need.

Common capabilities

Database → database
Users    → user_provider + group_provider
Auth     → actor_provider
Logs     → logger

Users.user_provider ─────→ Auth
Users.group_provider ────→ Permissions
Logs.logger ─────────────→ Auth / Users / Permissions
Auth.actor_provider ─────→ Logs / authorization context

What developers should normally see

$auth = new AuthManager();
$result = $auth->attempt($email, $password);

They should not need to call internal configuration methods when compatible resources can be discovered safely.

Inspection

When debugging, a module may expose diagnostics such as:

print_r($auth->explain());
print_r($users->explain());

Inspection belongs in debugging/reference documentation, not in normal getting-started examples.
