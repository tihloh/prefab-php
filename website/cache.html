Cache

Core provides small cache stores for shared infrastructure without deciding application caching policy for you.

1. In-memory cache

use Tihloh\Prefab\Core\Cache\ArrayCache;

$cache = new ArrayCache();

2. File-backed cache

use Tihloh\Prefab\Core\Cache\FileCache;

$cache = new FileCache(__DIR__ . '/../storage/cache');

3. Remember a value

$users = $cache->remember('users.all', 300, function () {
    return loadUsers();
});

The callback runs only when the cached value is unavailable or expired.

4. Keep policy in your application

Core provides storage mechanics. Your module or application decides what is safe to cache, TTL values and when writes should invalidate cached data.
