# Auth + Social Test Project

A tiny standalone PHP app for testing `tihloh/prefab-auth` without Laravel.

## Run

From this directory:

```bash
composer install
php -S 127.0.0.1:8080 -t public
```

Open `http://127.0.0.1:8080`.

## Test credentials

You can also click **Continue with Mock Google**. The mock provider follows the same state + redirect + callback flow used by a real OAuth provider, but it runs entirely locally and does not need credentials.

## What it demonstrates

- password login through `AuthManager`
- native PHP session storage
- `SocialProviderRegistry`
- OAuth state creation/validation
- social callback normalization through `SocialIdentity`
- existing-user resolution by email
- social account linking
- authenticated-user lookup
- logout
- structured log payloads generated by Auth

## Replace the mock provider with Google/GitHub

The test registers `CallbackSocialProvider`. Replace its authorization and callback closures with an OAuth SDK or Laravel Socialite adapter. The rest of the application does not change:

```php
header('Location: ' . $social->authorizationUrl('google'));

$result = $social->callback('google', $_GET);
```

That is the intended Prefab boundary: provider-specific OAuth code stays inside the provider adapter, while the project uses the same `SocialAuthManager` API.
